# Language QA MCP

A practical language review MCP for Korean proofreading, natural English, and Konglish detection.

## Documentation

- [한국어 사용법](./README.ko.md)
- [English Guide](./README.en.md)

## In one sentence

**Language QA checks Korean spelling and spacing, English grammar and naturalness, and Korean-influenced English while separating real errors from optional style suggestions.**

## Core capabilities

- Korean spelling, spacing, grammar, sentence agreement, punctuation, and natural phrasing
- English grammar, idiomatic naturalness, collocation, tone, and context fit
- Konglish and Korean-to-English translation patterns
- Mixed Korean-English copy review
- Minimal correction first, natural rewrite only when useful

Current version: `0.1.0`
