# Language QA MCP — 한국어 사용법

한국어 맞춤법·띄어쓰기부터 전문 윤문까지, 영어 문법·자연스러운 표현·콩글리시까지 함께 점검하는 MCP입니다.

## 한국어 교정 목표

단순한 맞춤법 검사기가 아니라 **국어 전문 편집자 수준의 윤문**을 목표로 합니다.

한국어 검토 시 다음 순서로 봅니다.

1. 원문의 의미와 사실을 보존합니다.
2. 맞춤법·띄어쓰기·문법 오류를 바로잡습니다.
3. 주어와 서술어, 목적어와 서술어, 수식어와 피수식어의 호응을 확인합니다.
4. 지나치게 긴 문장은 의미 단위로 나누고, 한 문장에 여러 판단이 겹치지 않게 정리합니다.
5. 겹겹이 붙은 수식어, 추상명사, 명사화, 번역투, 군더더기를 줄입니다.
6. AI 생성문에서 흔한 장황함, 반복되는 접속 표현, 과잉 설명을 줄입니다.
7. 문단의 중심 문장과 논리 흐름을 정리합니다.
8. 필자의 원래 말투와 문체는 가능한 한 보존합니다.

### 기준으로 삼는 원칙

- 국립국어원의 한국어 어문 규범(한글 맞춤법, 표준어 규정, 문장 부호, 외래어 표기 원칙)
- 표준국어대사전과 공식적인 표준 용례를 우선하는 편집 원칙
- 정확성·명료성·간결성을 중시하는 공공언어 문장 다듬기 원칙

> 이 MCP가 국어 자료를 새로 학습하거나 자체 언어 모델을 재훈련하는 것은 아닙니다. 대신 MCP의 검토 기준과 프롬프트에 위 원칙을 명시적으로 반영해, 연결된 AI 모델이 해당 기준으로 교정하도록 설계했습니다.

## 특히 줄이는 표현

- 한 문장 안에 `~하며, ~하고, ~하면서, ~하는 동시에`가 계속 이어지는 구조
- 의미가 비슷한 형용사·부사를 여러 개 겹치는 표현
- `~에 대한`, `~을 통해`, `~에 있어서`, `~부분`, `~것`, `~관련`이 연쇄되는 문장
- 주체가 보이지 않는 과도한 명사형·피동형 표현
- 같은 내용을 한 번 더 풀어 쓰는 과잉 설명
- 문단마다 비슷한 접속어와 결론 표현이 반복되는 AI식 리듬
- 원문보다 불필요하게 길어지는 윤문

## 문학·에세이 문장은 다르게 봅니다

무조건 짧게 쪼개지 않습니다. 문학적 문맥이나 에세이에서는 의도된 호흡, 반복, 여운, 리듬을 보존합니다. 다만 문장 성분의 호응이 깨지거나 의미가 모호해지는 경우에는 구조를 바로잡습니다.

## 권장 사용법 — 전문 윤문

```text
Language QA MCP의 korean_editorial_polish로 아래 글을 윤문해줘.

- 맞춤법·띄어쓰기·문법부터 확인
- 주어와 서술어 호응 점검
- 긴 문장과 수식어 중첩 정리
- 번역투와 AI식 장황한 표현 제거
- 원문의 의미와 말투는 유지
- 특별한 이유가 없으면 원문보다 길게 만들지 않기

원문:
[검토할 글]

문맥:
[예: 사내 공지 / 보고서 / 에세이 / 홈페이지 소개문]
```

## 일반 한국어 교정

```text
Language QA MCP의 korean_proofread로 아래 문장을 봐줘.
맞춤법, 띄어쓰기, 조사, 어미, 주어-서술어 호응을 먼저 확인하고
필수 수정과 선택적인 문체 개선을 구분해줘.

문장:
오늘 회의에서 이야기 했던 내용 정리해서 공유 드립니다.
```

## 영어

- 문법
- 관사·전치사
- 시제·수 일치
- 어색한 직역 표현

- 문맥과 톤에 맞는 표현
- 문법적으로 맞지만 원어민에게 어색한 문장

### 영어 문법 + 자연스러운 표현

```text
Language QA MCP의 natural_english로 아래 영어를 검토해줘.
문법 오류와 문법상 가능하지만 어색한 표현을 구분하고,
자연스러운 영어 대안을 제안해줘.

Text:
Happy thankful today.
Context: Instagram caption
```

## 콩글리시

한국에서 흔히 쓰이지만 영어권에서는 뜻이 다르거나 자연스럽지 않은 표현을 구분합니다.

```text
Language QA MCP의 konglish_check로 아래 표현을 확인해줘.
국제 영어에서 자연스러운지, 한국식 영어인지 구분하고
필요하면 자연스러운 대안을 제안해줘.

Text:
Let's do skinship after meeting at the pension.
```

## 한글+영어 혼용

```text
Language QA MCP로 아래 카피를 mixed 모드로 검토해줘.
한국어 띄어쓰기와 영어 표현을 함께 보고,
브랜드명이나 고유명사는 함부로 바꾸지 마.

Text:
이번 Leadership Workshop에서 우리 팀의 Action Plan을 같이 만들어봐요.
```

## 사용 가능한 기능

### Tool
`review_language`

입력:
- `text` — 검토할 문장/글
- `language` — `auto` / `ko` / `en` / `mixed`
- `tone` — `preserve` / `natural` / `concise` / `formal` / `warm` / `professional` / `casual`
- `context` — 이메일, UI 문구, 보고서, 에세이, 홈페이지 등
- `audience` — 대상 독자
- `explain_changes` — 수정 이유 설명 여부

### Prompts
- `korean_editorial_polish` — 전문 한국어 윤문
- `korean_proofread` — 맞춤법·띄어쓰기·문장 호응 중심 교정
- `natural_english` — 영어 문법 + 자연스러운 표현
- `konglish_check` — 콩글리시 및 한국식 영어 점검

## 권장 출력 방식

한국어 윤문 결과는 다음 순서로 정리합니다.

1. **최종 윤문본**
2. **필수 교정** — 객관적 오류만
3. **핵심 윤문 포인트** — 장문, 호응, 수식어, 번역투, AI식 표현 등 실제로 손본 부분만
4. **대안 표현** — 의미 있는 선택지가 있을 때만
